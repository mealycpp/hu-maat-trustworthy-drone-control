1. Purpose and context

Steering the wrong aircraft is a primary hazard of spoken fleet control. This algorithm computes, from the utterance alone, the exact set of addressed aircraft, or refuses with an explanation. It is used by the deterministic mission router (Algorithm 3) and, in a closely related form (stated_targets), as the named-address guard on the neural route (Algorithm 1). Neither form ever infers an aircraft that is not literally named or implied by a collective word.

2. Inputs and outputs

Input: lower-cased, whitespace-normalised utterance s; fleet N = (Horus, Ra, Thoth, Anubis, Osiris) in fixed order. Output of addresses(s): a pair (targets, problem) where exactly one is non-empty; targets are returned in fleet order. Output of stated_targets(u): a list, or None meaning "no explicit address stated".

6. Complexity

O(|N|·|s|) for the name scans plus a constant number of regular-expression searches.

7. Properties

Guaranteed

  • No inferred aircraft: a target is returned only if named, or implied by a collective minus a named exclusion.
  • Ambiguity refusal: any hedge word refuses the address (even if it appears elsewhere in the sentence; this is conservative).
  • Mixed forms ("all, Horus") and orphan exclusions ("except Ra" without ALL, or "all except" without a recognised name) are refused with a corrective message.
  • On the neural route, a model target set that differs in any element from an explicitly stated address is refused, never repaired.
  • An exclusion that removes every aircraft is refused ("That exclusion leaves no aircraft.").
  • Deterministic and order-stable output (fleet order).

Not guaranteed / limitations

  • The two resolvers disagree on exclusion lists. 4.1 removes every listed name ("all except Ra and Thoth" → Horus, Anubis, Osiris). 4.2 removes only the first listed name, and it treats plain all as collective only immediately before a listed verb. Plain take-off / land / hover / stop sentences are routed to HU (Algorithm 3), so for them only 4.2 is applied: for "All except Ra and Thoth, take off" it returns {Ra, Thoth}, the aircraft the operator excluded. A correct model prediction is then refused (safe direction); a model prediction of {Ra, Thoth} would pass the guard and could be dispatched. For "Everyone except Ra and Thoth, land" 4.2 returns the fleet minus Ra, so a correct prediction is refused. See Table 4.1. Not covered by a test.
  • The two vocabularies differ: e.g. "the fleet" is collective in 4.1 but not in 4.2; plain "all" is collective in 4.1 but in 4.2 only before listed verbs. Where 4.2 returns None it abstains.
  • Ordinal/indexed addressing ("drone two") is not resolved here (the HU model has an index feature, Algorithm 1).
  • Name matching is literal; mis-recognised names are handled only by the voice alias table and its confirmation step (Algorithm 19).

9. Comparison with alternatives and related work

Deciding which aircraft an utterance refers to is a reference-resolution problem. Established work resolves references from discourse context, from learned models, from perception, or by asking.

  • Discourse-based resolution (centering) [1]: an attentional state carried across utterances explains which entity a pronoun or reduced expression refers to.
  • Neural coreference resolution [2]: every span is scored as a possible mention and a distribution over antecedents is learned end to end.
  • Interactive grounding with clarifying questions [3]: candidates are scored against the referring expression and, when the reference is ambiguous, the robot asks a generated disambiguating question.
  • Selecting and grouping robots by attention and speech [4, 5]: the user looks at robots to select them; in [5] the user says how many ("you two"), forms a team that is then commanded as a unit ("take off"), and modifies it ("not you").

Where this resolver is weaker. It handles only the closed fleet of five literal names, has no notion of previous commands, of deictic or numeric selection, or of groups, and its two variants disagree on exclusion lists (Section 7). It never asks a specific question; the operator must restate the command. Where it differs. Its output is exact and explainable: no aircraft is ever inferred, and any hedge word causes refusal, which is the conservative choice for actuating vehicles; the methods above optimise resolution accuracy rather than refusal of uncertain references.
